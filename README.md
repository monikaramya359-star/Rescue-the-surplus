# 🍱 Rescue the Surplus
Rescue the Surplus is a web-based food rescue platform that connects restaurants and food providers with NGOs and individuals to reduce food waste and make surplus food accessible to people in need.

### ✨ Key Features
- User registration and login.
- Food providers can list surplus food.
- Recipients can explore available food.
- View restaurant name, location, quantity, pickup time, and distance.
- Request food for pickup.
- Manage and track pickup requests.
- Role-based access for different users.

### 🛠️ Tech Stack
- React
- TypeScript
- Tailwind CSS
- Supabase

### 🎯 Objective
To reduce food wastage, encourage food donations, and create a connection between surplus food providers and people who need it.

### 🌱 Vision
Turning surplus food into support for communities and building a sustainable, hunger-free future.
